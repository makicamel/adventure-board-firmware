# ピンとコネクタ

## マイコンのピン（GPIO）

| GPIO | つながっているもの |
|---|---|
| 2, 3 | J1（ブレッドボードの横）。I2C1 にもなる |
| 4, 5 | LED マトリクスのドライバ（I2C0） |
| 6, 7 | GROVE1（J4）。I2C1 の SDA / SCL |
| 8, 9 | J1 |
| 10 | スピーカー（音の出力） |
| 11 | J1。音の右チャンネルも出ている |
| 12, 13, 14, 15 | J1 |
| 16 | STATUS の緑 LED。J1 にも出ている |
| 17 | UP ボタン |
| 18 | LEFT ボタン |
| 19 | RIGHT ボタン |
| 20 | DOWN ボタン |
| 21 | B ボタン |
| 22 | A ボタン |
| 23 | スピーカーのアンプのオン・オフ |
| 24 | LED マトリクスのドライバのオン・オフ |
| 25, 26, 27 | J1。26 と 27 はアナログ入力（ADC）にもなる |
| 28, 29 | GROVE2（J5）。UART0 の TX / RX、またはアナログ入力 |

ボタンは押すと 0、離すと 1 です（基板の中で 3.3V に引き上げてある）。

## J1（ブレッドボード用の 2×10 ソケット）

基板の印刷のとおりに並んでいます。上が基板の上側です。

| 左の列 | 右の列 |
|---|---|
| G | G |
| 27 | G |
| 25 | 26 |
| 15 | 16 |
| 13 | 14 |
| 11 | 12 |
| 08 | 09 |
| 02 | 03 |
| G | 3V3 |
| 5V | G |

数字は GPIO の番号、`G` は GND（0V）です。

::: warning
**5V を GPIO につながないでください。** マイコンの GPIO は 3.3V までです。
:::

## GROVE

| | 信号 | 使い道 |
|---|---|---|
| GROVE1（J4） | GPIO6（SDA）、GPIO7（SCL） | I2C のセンサ、キーボードなど |
| GROVE2（J5） | GPIO28、GPIO29 | UART（シリアル通信）、アナログ入力、もう 1 枚の基板 |

どちらも **ふつうの Grove ケーブル** でつなげます。
電源（赤）は、**GROVE1 が 5V、GROVE2 が 3.3V** です（基板の 0Ω 抵抗の付け替えで変えられます）。

| ケーブルの色 | GROVE1 | GROVE2 |
|---|---|---|
| 黄 | SCL（GPIO7） | GPIO29（UART の RX） |
| 白 | SDA（GPIO6） | GPIO28（UART の TX） |
| 赤 | 5V | 3.3V |
| 黒 | GND | GND |

回路図（PDF）は [adventure-board-pcb](https://github.com/picorubykaigi/adventure-board-pcb) の `docs/adventure-board-schematic.pdf` にあります。
