# 4. ボタンで操作する

十字ボタンで点を動かします。

<<< @/snippets/buttons.rb

シミュレータでは、絵のボタンを押すか、キーボードの矢印キーで動きます。

## 押されたボタンを受け取る

```ruby
buttons = AdventureBoard.buttons
```

ボタンを取り出します。ボタンの名前は `:up` `:down` `:left` `:right` `:a` `:b` です。

```ruby
  buttons.each_press do |name|
    x -= 1 if name == :left
    ...
  end
```

`each_press` は、**前に聞いたときから今までに押されたボタン** を 1 つずつ取り出して、`name` に入れてくれます。
ボタンが押されたことは基板が覚えておいてくれるので、ループが遅くても、短く押しても取りこぼしません。

`x -= 1` は `x = x - 1` と同じ意味です。

## 押しているあいだ

「押しているあいだずっと」を知りたいときは `pressed?` を使います。

<<< @/snippets/buttons_held.rb

| 命令 | 返すもの |
|---|---|
| `each_press { \|name\| ... }` | 押されたボタンを 1 回ずつ |
| `take_press` | 押されたボタンを 1 つ（無ければ `nil`） |
| `pressed?(:a)` | いま押されているか（`true` / `false`） |
| `pressed` | いま押されているボタンの一覧 |

::: tip やってみよう
- A を押したら点を明るく、B で暗くしてみましょう
- 押しっぱなしで動き続けるようにしてみましょう（`pressed?` を使う）
:::
