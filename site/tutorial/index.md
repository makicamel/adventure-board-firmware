# チュートリアルの進め方

Adventure Board の各機能を試していきながら、使い方を学んでいきます。

## 動かし方

どのページのコードも、[コンソール](/console/){target="_blank"} のコードの欄に貼り付けて動かします。

- 基板が無いとき: **Run** でシミュレータが動きます
- 基板があるとき: **実機に接続** してから **実機で実行** を押します

コードの右上のボタンでコピーできます。
