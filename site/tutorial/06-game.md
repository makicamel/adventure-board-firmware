## しくみ

### 石を覚えておく

```ruby
rocks = []     # 落ちてくる石。1 つが [x, y]
```

石は `[x, y]` の組で、それを集めた配列（並び）が `rocks` です。
`rocks << [rand(16) + 1, 1]` で、いちばん上の段のでたらめな位置に石を足します（`rand(16)` は 0〜15 のどれか）。

### 石を落とす速さ

ループは 30 ミリ秒ごとに回っていますが、石が毎回落ちると速すぎます。
`tick`（何周したか）を数えて、`speed` 周に 1 回だけ落とします。

```ruby
  if tick % speed == 0
```

`%` は割り算の余りです。`tick % 6 == 0` は「6 周に 1 回」。`speed` はよけた数が増えるほど小さくなるので、だんだん速くなります。

### 当たったか

```ruby
  hit = rocks.any? { |r| r[1] == 16 && r[0] == x }
```

「いちばん下の段にあって、x が自分と同じ石が 1 つでもあるか」を調べます。`&&` は「かつ」です。

### 点を数える

下まで落ちきった石（y が 16 を超えたもの）は捨てて、その数だけ点を足します。

```ruby
  left = rocks.select { |r| r[1] <= 16 }   # まだ画面の中の石だけ残す
  score += rocks.size - left.size
  rocks = left
```
