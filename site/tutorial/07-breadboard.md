# 7. ブレッドボードで電子工作

基板の上のブレッドボードに LED やスイッチを挿して、プログラムから動かします。

## ブレッドボードと J1

ブレッドボードの穴は、**縦に 5 つずつ** 中でつながっています（溝の上の a〜e、下の f〜j）。
同じ列の 5 つの穴のどこに挿しても、つながり方は同じです。

ブレッドボードの右にある **J1** から、電源と GPIO を取ります。
GPIO は、プログラムから電圧を出したり（出力）、電圧を読んだり（入力）できるマイコンのピンです。

| J1 の印刷 | 意味 |
|---|---|
| `02` `03` `08` … `27` | GPIO の番号。プログラムでは `GPIO.new(2, ...)` のように使います |
| `G` | GND（0V） |
| `3V3` | 3.3V |
| `5V` | 5V（**GPIO にはつながないでください**） |

コンソールのシミュレータでも、ブレッドボードを押して拡大すると、部品を挿せます。
回路は本当に計算しているので、抵抗を入れ忘れると警告が出ます。

## LED を点滅させる

<<< @/snippets/breadboard_led.rb

### つなぎ方

コードの先頭の「配線:」のとおりに挿します。

1. J1 の `02`（GPIO2）から、ジャンパ線で a13 へつなぎます
2. 抵抗（1kΩ）を b13 と b9 に挿します
3. 青 LED の **長い足（＋）を c9**、短い足（−）を溝の向こうの g10 に挿します
4. h10 から、ジャンパ線で J1 の `G` へつなぎます

電気は GPIO2 → 抵抗 → LED → GND と流れます。LED は向きがあるので、逆に挿すと光りません。
抵抗は、LED に流れる電気を小さくして、LED と GPIO を守ります。

::: tip シミュレータで配線する
サンプルの一覧から「ブレッドボードの LED」を選ぶと、この配線が自動で挿さります。
自分で挿すときは、ブレッドボードの下の「▸ 配線を文字で見る・貼り付ける」に次を貼り付けて「この配線にする」を押します。
```text
wire J1-5 a13
resistor b13 b9
led c9 g10
wire h10 J1-3
```
:::

### プログラム

```ruby
led = GPIO.new(2, GPIO::OUT)   # GPIO2 を出力にする
led.write(1)                   # 3.3V を出す
led.write(0)                   # 0V にする
```

## スイッチで LED を点ける

タクトスイッチを足して、押しているあいだだけ LED を点けます。

<<< @/snippets/breadboard_switch.rb

### つなぎ方

LED は上と同じです。それに加えて:

1. タクトスイッチを、溝をまたいで e3・e5・f3・f5 に挿します
2. J1 の `03`（GPIO3）から a3 へつなぎます
3. a5 から J1 の `G` へつなぎます

タクトスイッチは、押すと 3 列目と 5 列目がつながります。押すと GPIO3 が GND とつながって 0V になります。

::: tip シミュレータで配線する
「▸ 配線を文字で見る・貼り付ける」に貼り付けます。スイッチは「動かす・押す」を選んでから押します。
```text
wire J1-5 a13
resistor b13 b9
led c9 g10
wire h10 J1-3
switch e3
wire J1-6 a3
wire a5 J1-2
```
:::

### プログラム

```ruby
switch = GPIO.new(3, GPIO::IN | GPIO::PULL_UP)
```

GPIO3 を入力にします。`GPIO::PULL_UP` は「何もつながっていないときは 3.3V（1）にしておく」という意味です。
これが無いと、スイッチを押していないときの値が決まらず、読むたびに変わってしまいます。

`switch.read` は、3.3V なら 1、0V なら 0 を返します。押すと 0 です。

::: warning 気をつけること
- LED には必ず抵抗を入れてください。GPIO に直接つなぐと、大きな電気が流れます
- 3V3 や 5V を、G（GND）と直接つながないでください
- GPIO に 5V をつながないでください
:::
