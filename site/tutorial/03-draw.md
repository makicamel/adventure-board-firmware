# 3. 線と文字を描く

1 つずつ `set` するかわりに、線・四角・文字をまとめて描けます。

<<< @/../sim/examples/03_draw.rb

## 描いてから写す

線や文字は、いったん **描くための場所**（VRAM と呼びます）に描いてから、LED に写します。

| 命令 | すること |
|---|---|
| `clear_drawing` | 描く場所をまっさらにします |
| `draw_rect(x, y, 幅, 高さ, 明るさ)` | 四角の枠を描きます |
| `draw_line(x1, y1, x2, y2, 明るさ)` | 線を描きます |
| `draw_text(文字, x, y)` | 文字を描きます |
| `set_pixel(x, y, 明るさ)` | 点を 1 つ描きます |
| `blit` | 描いたものを LED マトリクスに写します |
| `show` | LED に送ります（`set` のときと同じ） |

::: warning 座標の数え方が違う
描く命令の座標は、左上が **`(0, 0)`**、右下が `(15, 15)` です（`set` は `(1, 1)` 〜 `(16, 16)`）。
:::

## 漢字を出す

16×16 の文字（フォント）が入っているので、漢字がちょうど 1 文字収まります。

<<< @/../sim/examples/03_kanji.rb

## 文字を流す

16 ドットには 1 文字しか入らないので、長い文字は流して見せます。
`draw_text` の x を 1 ずつ減らしていくと、文字が左へ動きます。

<<< @/../sim/examples/03_scroll.rb

`matrix.pen` は、文字の明るさです（`draw_text` には明るさを渡せないので、先に決めておきます）。

`text.size * 16` は、文字列の幅のだいたいの値です。漢字やひらがなは 16 ドット、英数字は 8 ドットの幅なので、
英数字が多いと、流れきってから右に戻るまで、何も出ていない時間が長くなります。

::: tip やってみよう
- 自分の名前を流してみましょう
- `draw_text` の y を変えて、文字を上下にずらしてみましょう
:::
