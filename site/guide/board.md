# 基板の各部

![Adventure Board](/images/board.webp){.board-photo}

## 表側

| 場所 | 部品 | 説明 |
|---|---|---|
| 中央 | **LED マトリクス** | 白い LED が 16×16 = 256 個。1 つずつ明るさを変えられる |
| 中央の下 | **ブレッドボード**（赤） | 部品を挿すだけで回路が組める。右にある J1 から電源と GPIO（マイコンの入出力のピン）を取る |
| 左下 | **十字ボタン**（UP / LEFT / RIGHT / DOWN） | |
| 右下 | **A / B ボタン** | |
| 左 | **スピーカー**（灰色の四角） | |
| 右上 | **USB-C** | パソコンとつなぐ。電源もここから |
| USB の横 | **POWER**（赤い LED） | 電源が入っていると点く。プログラムからは変えられない |
| USB の下 | **STATUS**（緑の LED） | プログラムから点けたり消したりできる |
| 右 | **BOOT / RST ボタン** | RST は基板のリセット（電源の入れ直しと同じ）。BOOT は [ファームウェアの書き込み](./firmware) で使う |
| 左上 | **GROVE2**（J5） | UART（シリアル通信）か、アナログ入力に使える |
| 左 | **GROVE1**（J4） | I2C のセンサなどをつなぐ |
| USB の下 | J2 | 開発用（デバッグ用の端子）。ふだんは使わない |

ボタンの名前は、基板に印刷されている文字（シルク）のとおりです。プログラムでは
`:up` `:left` `:right` `:down` `:a` `:b` と書きます。

## LED マトリクスの座標

左上が `(1, 1)`、右下が `(16, 16)` です。x が横（右へ増える）、y が縦（下へ増える）。

```text
 (1,1) ───────────── (16,1)
   │                    │
   │      16 × 16       │
   │                    │
 (1,16) ──────────── (16,16)
```

線や文字を描く命令（`draw_rect` など）だけは、左上が `(0, 0)` から数えます。
くわしくは [チュートリアル 3](/tutorial/03-draw) で。

## 電気のこと

- 電源は USB からの 5V です。マイコンや LED は 3.3V で動いています
- **LED を全部いちばん明るくして、同時に大きな音を出すと、USB から取れる電流（500mA）を超えることがあります。**
  明るさはほどほどに（[ライブラリ](/reference/library#ledmatrix) の `brightness`）
- J1 の GPIO に 5V をつながないでください。マイコンが壊れます

ピンの番号は [ピンとコネクタ](/reference/pins) にまとめてあります。
