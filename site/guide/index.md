# Adventure Board とは

Adventure Board は、PicoRubyKaigi 2026 Assemble のために作った学習用の基板です。
マイコン（Raspberry Pi の RP2350）の上で **PicoRuby**（小さなコンピュータ向けの Ruby）が動き、
書いた Ruby のプログラムで LED を光らせたり、音を鳴らしたり、ボタンを読んだりできます。

![Adventure Board](/images/board.webp){.board-photo}

## できること

- 16×16 の LED マトリクスに、点・線・文字（漢字も）を描く
- スピーカーでメロディや効果音を鳴らす
- 6 つのボタンで操作するゲームを作る
- ブレッドボードに LED やスイッチを挿して、電子工作をする
- GROVE コネクタにセンサなどをつなぐ

## 用意するもの

| もの | 説明 |
|---|---|
| Adventure Board | この基板 |
| USB ケーブル（USB-C） | パソコンとつなぎます。電源もここから取ります。**充電専用のケーブルでは通信できません** |
| パソコン | **Chrome か Edge** が動くもの。ブラウザから基板にプログラムを送ります（Windows / macOS / Linux / Chromebook） |

基板がまだ手元に無くても、[コンソール](/console/){target="_blank"} のシミュレータでほとんどのことを試せます。
