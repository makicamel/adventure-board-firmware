# Adventure Board とは

Adventure Board は、PicoRubyKaigi 2026 Assemble のために開発した基板です。
マイコン（Raspberry Pi Pico2 でも使われている RP2350）の上で **PicoRuby**が動きます。

PicoRubyは、事前にコンパイルが不要で、書いた Ruby が直接基板上で動き、LED を光らせたり、音を鳴らしたり、ボタンの状態を読むことができます。

![Adventure Board](/images/board.webp){.board-photo}

## できること

- 16×16 の LED マトリクスに、点・線・文字 を描きます（漢字も描けます）
- スピーカーでメロディや効果音を鳴らします
- 6 つのボタンで操作します
- ブレッドボードに LED や液晶を挿して、電子工作をします
- GROVE コネクタに市販のセンサなどをつなぎます

## 用意するもの

| もの | 説明 |
|---|---|
| Adventure Board | この基板 |
| USB ケーブル（USB-C） | パソコンとつなぎます。電源もここから供給します。**パソコンと通信するので、通信可能なケーブルが必要です** |
| パソコン | **Chrome か Edge** ブラウザが動くもの。ブラウザでコンソールを開いてWebSerialを使って、基板にプログラムを送ります |

基板が手元に無くても、[コンソール](/console/){target="_blank"} のシミュレータでほとんどのことを試せます。

## ドキュメントの読み進め方

1. [基板の各部](./board) ：基板の機能を理解します
2. [コンソールを使う](./console) ：プログラムを書いて、シミュレータおよび実機で動かす方法を確認します
3. [チュートリアル](/tutorial/) ：いくつかのサンプルプログラムを読んで、開発の仕方を学びます

基板の中のファイルを直接さわりたくなったら [基板のシェル](./shell)、
ファームウェア（基板に書き込んであるR2P2）を新しくしたいときは [ファームウェアの書き込み](./firmware) を見てください。
