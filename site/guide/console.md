# コンソールを使う

[Adventure Board Console](/console/){target="_blank"} は、ブラウザで開く Adventure Board の道具箱です。

- **シミュレータ**: 画面の中の基板で、書いたプログラムをそのまま動かす
- **実機につなぐ**: USB でつないだ本物の基板に、同じプログラムを送って動かす

どちらも同じコードで動きます。シミュレータで動いたものは、そのまま基板でも動きます。

::: tip ブラウザ
シミュレータはどのブラウザでも動きます。実機につなぐには **Chrome か Edge** が要ります
（Web Serial という、ブラウザから USB の機器と話す仕組みを使うため）。
:::

## シミュレータで動かす

1. [コンソール](/console/){target="_blank"} を開く
2. 下のコードの欄に Ruby を書く（サンプルの一覧から選んでもよい）
3. **Run** を押す

左の基板の絵の LED が光ります。ボタンは絵の上を押すか、キーボードの **矢印キー / Z（A ボタン）/ X（B ボタン）** で押せます。

| ボタン | すること |
|---|---|
| サンプルの一覧 | 用意してあるサンプルをコードの欄に読み込む |
| **Run** | 前に動いていたものを止めて、コードの欄のプログラムを動かす。音もここで出せるようになる |
| シミュレータをリセット | 画面の中の基板の電源を入れ直す。おかしくなったら押す |
| ▸ 鳴った音を見る | いつ、どの音が鳴ったかの記録。音が聞こえないときの確認に |
| ▸ ライブラリのコードを見る | `AdventureBoard` の中身（基板に入っているものと同じ） |

LED マトリクスやブレッドボードを押すと拡大します。ブレッドボードには部品を挿せます
（[チュートリアル 7](/tutorial/07-breadboard)）。

## 実機につなぐ

1. 基板をパソコンに USB でつなぐ
2. **実機に接続** を押す
3. ブラウザがポートの一覧を出すので、基板を選ぶ。**同じ基板が 3 つ並ぶので、いちばん下（最後のもの）** を選ぶ
4. 下の「実機端末(xterm)」に `$>` が出たらつながっている

| ボタン | すること |
|---|---|
| 実機に接続 / 切断 | 基板とつなぐ・切る |
| **実機で実行** | 動いているものを止めて、コードの欄のプログラムを基板に送って動かす。その場で動くだけで、電源を入れ直しても動かない（基板には `/home/run.rb` として残る） |
| 実機の app.rb にする | コードの欄のプログラムを、**電源を入れるたびに動く**ようにする（[チュートリアル 8](/tutorial/08-app)） |
| 実機を再起動 | 基板をリセットする。`app.rb` があればそれが動く |
| 実機の app.rb を空にする | 電源を入れても何も動かない基板に戻す |

「実機端末(xterm)」は本物の端末です。キーを打てば、基板のシェルをそのまま使えます（[基板のシェル](./shell)）。
動いているプログラムを止めるには、端末で **Ctrl-C** を押します。

::: warning うまくつながらないとき
- 一覧に基板が出ない: USB ケーブルが充電専用でないか確かめる。別のケーブルや別の USB の口を試す
- `$>` が出ない: 選んだポートが違う。いったん切断して、一覧のほかのものを選ぶ
- 再起動すると一度 USB が切れますが、基板が起動し終わると自動でつなぎ直します
:::
