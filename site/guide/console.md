# コンソールを使う

[Adventure Board Console](/console/){target="_blank"} は、ブラウザで開く Adventure Board の道具箱です。

- **シミュレータ**: 画面の中の基板で、書いたプログラムをそのまま動かします
- **実機につなぐ**: USB でつないだ本物の基板に、同じプログラムを送って動かします

どちらも同じコードで動きます。シミュレータで動いたものは、そのまま基板でも動きます。

::: tip ブラウザ
シミュレータはどのブラウザでも動きます。実機につなぐには **Chrome か Edge** が要ります
（Web Serial という、ブラウザから USB の機器と話す仕組みを使うため）。
:::

## シミュレータで動かす

1. [コンソール](/console/){target="_blank"} を開きます
2. 下のコードの欄に Ruby を書きます（サンプルの一覧から選んでもかまいません）
3. **Run** を押します

左の基板の絵の LED が光ります。ボタンは絵の上を押すか、キーボードの **矢印キー / Z（A ボタン）/ X（B ボタン）** で押せます。

| ボタン | すること |
|---|---|
| サンプルの一覧 | 用意してあるサンプルをコードの欄に読み込みます |
| **Run** | 前に動いていたものを止めて、コードの欄のプログラムを動かします。音もここで出せるようになります |
| シミュレータをリセット | 画面の中の基板の電源を入れ直します。おかしくなったら押します |
| ▸ 鳴った音を見る | いつ、どの音が鳴ったかを見ます。音が聞こえないときの確認に使えます |
| ▸ ライブラリのコードを見る | `AdventureBoard` の中身を見ます（基板に入っているものと同じです） |

LED マトリクスやブレッドボードを押すと拡大します。ブレッドボードには部品を挿せます
（[チュートリアル 7](/tutorial/07-breadboard)）。

## 実機につなぐ

1. 基板をパソコンに USB でつなぎます
2. **実機に接続** を押します
3. ブラウザがポートの一覧を出すので、基板を選びます。**同じ基板が 3 つ並ぶので、いちばん下（最後のもの）** を選びます
4. 下の「実機端末(xterm)」に `$>` が出たらつながっています

| ボタン | すること |
|---|---|
| 実機に接続 / 切断 | 基板とつないだり、切ったりします |
| **実機で実行** | 動いているものを止めて、コードの欄のプログラムを基板に送って動かします。その場で動くだけで、電源を入れ直しても動きません（基板には `/home/run.rb` として残ります） |
| 実機の app.rb にする | コードの欄のプログラムを、**電源を入れるたびに動く**ようにします（[チュートリアル 8](/tutorial/08-app)） |
| 実機を再起動 | 基板をリセットします。`app.rb` があればそれが動きます |
| 実機の app.rb を空にする | 電源を入れても何も動かない基板に戻します |

「実機端末(xterm)」は本物の端末です。キーを打てば、基板のシェルをそのまま使えます（[基板のシェル](./shell)）。
動いているプログラムを止めるには、端末で **Ctrl-C** を押します。

::: warning うまくつながらないとき
- 一覧に基板が出ない: USB ケーブルが充電専用でないか確かめます。別のケーブルや別の USB の口を試します
- `$>` が出ない: 選んだポートが違います。いったん切断して、一覧のほかのものを選びます
- 再起動すると一度 USB が切れますが、基板が起動し終わると自動でつなぎ直します
:::
