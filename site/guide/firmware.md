# ファームウェアの書き込み

ファームウェアは、基板の中で動いている基本ソフト（PicoRuby と R2P2、`AdventureBoard` のライブラリ）です。

**配布した基板には、最初から書き込んであります。** 届いたらそのまま使えるので、このページの作業は要りません。
新しい版が出たときに、ここの手順で書き込み直してください。

## 1. ファイルを手に入れる

[リリースのページ](https://github.com/picorubykaigi/adventure-board-firmware/releases) から、
いちばん新しい版の `.uf2` ファイルをダウンロードします。`adventure-board-2026.10.31.uf2` のような名前で、数字は版を出した日付です。

## 2. 書き込む

1. 基板の USB ケーブルを抜く
2. **BOOT ボタンを押したまま** USB ケーブルを挿す。挿したらボタンを離してよい
3. パソコンに `RP2350` という名前のドライブ（USB メモリのようなもの）が出てくる
4. ダウンロードした `.uf2` ファイルを、そのドライブにドラッグ&ドロップする
5. コピーが終わると基板が自動で再起動し、ドライブは消える

USB を挿したままでも、**BOOT を押したまま RST を押して離す** と同じ状態になります。

## 書き込んだあと

最初の起動で、ライブラリ（`/lib`）とサンプル（`/home/examples`）が書き出されます。

- `/lib` のライブラリは、新しい版のものに置き換わります
- `/home/examples` には、新しく増えたサンプルだけが足されます。**前からあるサンプルと、自分で作ったファイルはそのまま残ります**
  （書き換えたサンプルが上書きされないように）。新しい版のサンプルに入れ替えたいときは、
  そのファイルを `rm` で消してから、新しいファームウェアを書き込んでください
