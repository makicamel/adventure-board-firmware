最初の計画: [plan.md](plan.md)（2026-09-14 午前。候補の洗い出しと当初の手順）。
このファイルは、**実際に試したこと・分かったこと・外れた仮説・次にやること**の記録。

## 0. 要点（ここだけ読めば続けられる）

- 症状: スピーカーの音が「ざらざら」「びりびり」「割れている」。r1 でも USB を直した基板でも同じ
- **PSG（音源ライブラリ）を通さない素の PWM でも同じくざらざら**（T1）。原因は PSG ではない
- **GPIO10（音声のピン）が PWM で切り替わっているあいだだけ、ホワイトノイズに近い強いノイズが出る**
  - 0V 固定・3.3V 固定では出ない（T0, T12）
  - **周波数によらない**: 20kHz〜2MHz のどれでも同じくらい（T10）
  - **デューティ 50% で最大、10% / 90% で小さい**（T12）
  - 音声に繋がっていない GPIO15 で同じ PWM を出しても出ない（T11）
- 基板は **4 層で内層に全面の GND ベタ**がある（§3b）。そのため「充放電電流が GND を回り込む」説（H）は
  有力とは考えにくくなった
- **今の候補**（§4b）: ① フィルタを抜けた PWM のキャリアがアンプを飽和・誤動作させている
  ② アンプの出力が自分の入力に回り込んでいる（発振に近い状態） ③ GND / 電源の回り込み
- **次にやること（§5）**: **0Ω（R44 / R45）は剥がすと戻せない前提**で、A（剥がす前: 20kHz と 2MHz の聴き比べ、
  J6 を GND に短絡、GPIO11 に負荷、オシロ）を全部済ませてから、B（R45 を外して PWM と外部音源で「アンプ以降か前段か」を
  分け、R44 も外して J3 → ブレッドボード → J6 の外付けフィルタで定数を試す）

## 2. 音の経路（ハード）

```
GPIO10 ─[J3]─ R44 0Ω ─ R14 1kΩ ─┬─ R10 1kΩ ─┬─ R45 0Ω ─[J6]─ C24 100nF ─ R9 47kΩ ─ PAM8302A IN+
                                C22 3.3nF   C25 3.3nF                    PAM8302A IN− ─ R6 47kΩ ─ C23 100nF ─ GND
                                  GND         GND
PAM8302A: VDD = 5V（USB 由来）、SD = GPIO23（Low でミュート）、出力 → R46/R47 0Ω → LS1（8Ω 0.7W）
```

- J3 / J6 はテストポイント。**J3 は R44 より GPIO10 側**（生の PWM。R44 を外しても出ている）、
  J6 は R45 よりアンプ側（C24 の入口。R45 を外しても出ている）
- **R44 / R45（0Ω）は外して切り離すための部品**（設計者の意図）。R44 を外すとマイコンと基板上のフィルタが、
  R45 を外すとフィルタとアンプが切れる。両方外すと **J3 → ブレッドボード → J6 で外付けフィルタを組める**。
  ⚠ **0Ω は一度剥がすと戻すのが面倒**（一方通行と考える）。剥がす前に、元の経路で要る試験を全部済ませる
- **R41 / R42（68kΩ、未実装）はゲインを変えるための交換用**
- R41 / R42（68kΩ、未実装）はゲイン調整用
- PAM8302A: フィルタなし D 級、ゲイン 23.5dB（データシート）、**内部発振 fOSC = 200〜300kHz（標準 250kHz）**
- RC フィルタ（1kΩ + 3.3nF の 2 段）の −3dB は約 18kHz。計算の表は plan.md §1
- 基板の設計方針書（`tmp/picorubykaigi01-board/docs/PicoBoard_design_policy.md` §4.3）は
  「10bit・146.5kHz の PWM」を前提にこのフィルタを選んでいた

## 4. 仮説の変遷

| # | 仮説 | 根拠にしたこと | 判定 | 決め手 |
|---|---|---|---|---|
| A | PSG の PWM キャリア 22.5kHz がフィルタで落ちずアンプに入る | コードとフィルタ計算 | **主因ではない** | T1（PSG なし）もざらざら |
| B | PSG の矩形波の折り返し雑音 | コード | **主因ではない** | 同上 |
| C | 特定周波数の共振（スピーカー・基板のビビり） | — | **否定** | T7 で全域 |
| D | アンプの入力オーバーでクリップ | T1 が「割れている」 | **未決着だがノイズの主因ではない** | T0-3 は無音信号でもノイズ |
| E | フィルタを抜けた高周波が fOSC（250kHz）と混ざって可聴域に落ちる | fOSC = 200〜300kHz | **否定** | T10: 2MHz（フィルタで −60dB 以上）でも同じノイズ |
| F | PWM の切り替え電流が基板全体の GND / 電源を揺らす | — | **否定** | T11: GPIO15 の PWM では無音 |
| G | 3.3V 電源のノイズが High のあいだ GPIO10 を素通りする | — | **否定** | T12: 3.3V 固定では無音。ノイズはデューティに比例せず 50% で最大 |
| H | GPIO10 → R14 → C22 の充放電電流が、GND の戻り道でアンプ入力側に回り込む | 下記 | **配線を読んで格下げ**（内層に全面の GND ベタ）。§4b の ③ として残す | GPIO11 にヘッダで負荷を付ける |

### H がこれまでの結果と合う理由

- C22 は十分高い周波数では交流的にほぼショート。R14 を流れる電流は ±(1.65V 付近)/1kΩ の矩形波で、
  **大きさが周波数によらない**（T10 と合う）
- その電流の交流成分は **d×(1−d) で決まり、50% で最大**（T12 と合う）
- 0V / 3.3V 固定では電流が流れない（T0-2, T12-1/2 と合う）
- GPIO15 には負荷が無いので電流が流れない（T11-2 と合う）
- アンプの入力は IN+ 側が C24/R9、IN− 側が R6/C23 で GND に落ちている。
  **C22 / C25 の GND 電流と C23 の GND の間に電位差ができれば、それは差動入力として増幅される**
- 回り込んだ高周波は、fOSC 250kHz でスイッチングするアンプの中で可聴域に折り返され、ホワイトノイズ状になりうる
- 音を出している間は必ず PWM が切り替わるので、**どんな音にもこのノイズが乗る**（T1 のざらざら）

### H の再評価（配線を読んだあと）

内層に全面の GND ベタがある基板で、R14 を流れる ±1.7mA 程度の高周波電流が、60mm 離れたアンプ入力に
「強いノイズ」として現れるのは考えにくい。**H は候補から外さないが、有力とは見なさない。**

### 4b. 考え直した候補（2026-09-14 夕方）

| # | 候補 | 合うこと | 弱点 | 決め手になる試験 |
|---|---|---|---|---|
| **①** | **フィルタを抜けた PWM のキャリアが、アンプを飽和・誤動作させている。** フィルタは設計想定（146.5kHz のキャリア）より弱く、20kHz で −4dB、150kHz でも −21dB。アンプ入力に 0.1〜1V のキャリアが入ると、可聴域外の信号でアンプが振り切れ、内部の 250kHz スイッチングと混ざってハッシュ状の音になりうる | T0-3・T12 の d(1−d) 依存、GPIO15 で無音、固定電圧で無音 | **2MHz ならフィルタで −64dB（約 1mV）になるはずで、T10「2MHz でも同じ」と合わない。** ただし耳で「似ている」と判定しただけ。アンプが飽和していると 150kHz 以下ではどれも同じ大きさに聞こえうる | T13（20kHz と 2MHz の A/B）、J6 短絡 |
| **②** | **アンプの出力（VO±）が自分の入力に回り込んでいる。** 出力と高インピーダンスの入力節が隣接し、フィルタ途中の 85mm の信号線も出力部の近くを通る。入力に高周波が入って出力が差動で振れ始めると、戻ってきて増える（発振に近い） | 「ホワイトノイズのような強い音」、周波数によらないことと相性がよい。入力ゼロなら出力は同相で安定 | 条件付きの現象で、実測でしか確かめられない | J6 短絡でも残るか、オシロで VO± と入力節 |
| ③ | GND / 電源の回り込み（= H） | T0〜T12 | 内層 GND ベタ | GPIO11 にヘッダで負荷を付ける |
| ④ | アンプ入力の過大でクリップ（T1 の「割れ」） | T1 | ノイズの主因ではない（無音信号でも出る） | T9（音量を下げる）、オシロでスピーカー端子 |

### H で説明しきれていない点（記録として残す）

- 「割れている」感じ（T1）は、クリップ（D）が別に重なっている可能性がある
- R14 の電流は数 mA 程度。これで聞こえるほどの電位差になるには、GND の戻り道がかなり悪い必要がある。
  配線を読んだ結果（§3b）、GND は内層の全面ベタで、戻り道が悪いとは言えない

## 5. 次にやること（改訂版。0Ω を剥がすのは一方通行）

R44 / R45（0Ω）と R41 / R42 は外す・付け替える前提で設計されているが、**0Ω は一度剥がすと戻すのが面倒**。
そこで **A. 剥がす前に元の経路でやる試験** と **B. 剥がしてからの試験** に分ける。B に入ったら基板上のフィルタは
使わず、外付けフィルタで代用する。それ以外の SMD は触らない。直す前に方針をユーザーに示して合意を取る。

### A. 剥がす前（元の経路が要る試験。全部済ませてから B へ）

| 順 | 試験 | 要るもの | 分かること |
|---|---|---|---|
| A-1 | **20kHz ↔ 2MHz の聴き比べ**（`t13_ab_frequency.rb`。無音を挟んで 3 回、最後に 5kHz / 10kHz） | なし | 「周波数によらない」の確かめ直し。2MHz が明らかに小さければ ①（キャリア）が本命 |
| A-2 | **J6 を GND にジャンパで短絡**したまま `t0_silence.rb`（150kHz 50%） | ジャンパ線 1 本 | ノイズが信号線経由か。J6 の手前に 1kΩ×2 があるので最大 1.7mA で安全。**J3 は短絡しない**（GPIO 出力の直接短絡になる） |
| A-3 | ヘッダの **GPIO11** で 150kHz 50%。無負荷 → 1kΩ + 3.3nF を GND へ | ブレッドボード部品 | 負荷の充放電電流が GND / 電源を回り込むか（③）。`t11_other_pin.rb` の 15 を 11 に変える。⚠ GPIO10 と同じスライスなので PSG を使う前に |
| A-4 | **オシロ**（持ってきてから）: J6、スピーカー端子（VO+ − VO−）、C23 の両端、J3、C27（5V） | オシロ | 元の経路でアンプ入力に届いているキャリアの振幅（計算値: 20kHz で約 1V、150kHz で約 0.15V、2MHz で約 1mV）と、出力の暴れ。①/② の直接の証拠 |
| A-5 | 参考: PSG のテスト `t2_t3_psg_tone.rb`、`t8_psg_pan.rb`、`t9_psg_level.rb` | なし | 元の経路での PSG の音を記録しておく（B のあとでは同じ条件で聴けない）。S4 のパンの確認も |

オシロのプローブの GND は、測る点の近く（C23 / C27 の GND 側パッド）に取る。長い GND リードは 250kHz の
スイッチングを拾い、それ自体がノイズに見える。

### B. 剥がしてから（一方通行）

**B-1. まず R45 だけ外す**（フィルタとアンプ入力が切れる。基板上のフィルタは GPIO10 に繋がったまま）

1. GPIO10 で 150kHz 50% の PWM（`t0_silence.rb`）。アンプには何も入っていない
   - **ノイズが出る** → 信号線を通らずに届いている（③、または空間的な結合）
   - **静か** → ノイズは信号線を通って入っている（① か ②）
2. **J6 に外部からきれいな音**（スマホ / PC のイヤホン出力。片チャンネルを J6、GND を GND に。
   1Vpp 程度でアンプのゲインは約 2.6 倍なので安全）。`t14_amp_only.rb` で SD を High にして聴く
   - **きれい** → アンプ・スピーカー・周辺は健全。原因は前段（①）
   - **ざらざら** → アンプ以降の問題（②、電源、スピーカー）

**B-2. 次に R44 も外す**（基板上のフィルタが完全に浮く。J3 = 生の GPIO10、J6 = アンプ入口）

- **J3 → ブレッドボード → J6 で外付けフィルタ**を組む。まず元と同じ 1kΩ + 3.3nF ×2 で、元の音が再現するか
  （B-2 以降の基準になる）
- 次に強くする: 1kΩ + 10nF ×2（−3dB 約 6kHz、150kHz で約 −40dB）、または 3 段目を足す
  - ①（キャリア）なら、フィルタを強くしただけでノイズが減る。減り方が r2 の定数決めにそのまま使える
  - 減らないなら ②/③
- 同じ配線で、PSG のキャリアを上げるソフト改修（§5-5）の効果も先に確かめられる
- GPIO10 は J3 から取る。GPIO11（ヘッダ）で代用するときは PSG のパンを右に振る必要があるので、J3 のほうが楽

**B-3. R41 / R42（ゲイン）**は、原因が決まってからの対策側で扱う

### 5-5. 候補ごとの対策（当たったときに何が要るか）

| 候補 | ソフト | 今の基板 | r2 の基板 |
|---|---|---|---|
| **①** キャリアがフィルタを抜けてアンプを飽和させる | PSG の PWM キャリアを 22.5kHz → 約 132kHz（比較値の上限 1132、1 サンプルを DMA で 6 回書く。`mrbgems/picoruby-psg/ports/rp2040/psg_drv_pwm.c`、**upstream の gem**）。素の `picoruby-pwm` の矩形波には無関係 | R44/R45 を外して J3 → ブレッドボード → J6 に強いフィルタ（定数決め用）。R45 を残すなら J6–GND に 10nF 程度を足す（2 段目が強くなり 150kHz で約 −10dB 改善） | C22/C25 を 10nF 程度（−3dB 約 9kHz）か 3 段目を追加。**注意: 設計どおり 146.5kHz にしても今の定数では −22dB で、0.17V のキャリアが残る。**キャリアを上げるだけでは足りない |
| **②** アンプの出力が入力に回り込む | なし | R46/R47 の 0Ω をフェライトビーズに（0805。データシート推奨）。スピーカーの線を短く。J6–GND に数百 pF〜1nF で入力節の高周波インピーダンスを下げる | VO± と IN±（R6/R9/C23/C24）を離す。85mm の信号線を出力・スピーカー側から離す。ビーズと入力小容量のパッド。入力の 47kΩ を分圧に変えて入力節を低インピーダンスに |
| **③** GND / 電源の回り込み | なし | 外付けフィルタの GND をアンプ側（C23 の近く）に取る程度 | フィルタ 2 段をアンプのそばに置き、C22/C25/C23 の GND を一点に。基板を横切る 85mm はフィルタ後のアナログではなく生のデジタル PWM にする。アンプ GND の分離と一点接続 |
| **④** 入力過大でクリップ（T1 の「割れ」） | PSG の出力に上限（1 声 v15 矩形波は基本波約 2.1V × ゲイン 2.6 = 5.5V > 5V）。v12 程度を上限にするか `Board` の既定音量を下げる。「左に振って +3dB」は逆方向なので外す | R41/R42（ゲイン上げ）は**付けない** | 入力を分圧で下げる |

- ① と ④ はソフトと定数で今の基板でも改善できる。② と ③ は r2 の配線が本筋で、今の基板ではビーズ程度
- どの候補でも、PSG の PWM が無音時 0V で音が片側だけに振れる作り（S7）はポップ音の原因。直流の中心を真ん中に置く改修は別途価値がある

### 5-6. 別件（§6）は原因と独立に直せる
