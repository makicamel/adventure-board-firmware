## J2 の押し当て治具（r1 用に作る。r2 でも使う）

- 先端が尖ったポゴピン（P75-B1 系）5 本を 2.54mm ピッチで並べ、スルーホールに上から当てる。尖った先端が穴に落ちて位置が決まる
- 反対側は 1×5 のピンヘッダにして、Debug Probe 付属のケーブル（SWD 用 3 ピン、UART 用 3 ピン）をジャンパで受ける。並びは J2 のまま: 1=GND 2=SWCLK 3=SWDIO 4=UART_RX(GPIO1)←プローブ TX 5=UART_TX(GPIO0)→プローブ RX
- 書き込みは十数秒、起動ログでも数分なので、手で押さえるか輪ゴムで留める
- **市販の「2.54mm ピッチ PCB クリップ治具（ポゴピン付き、1 列 5P）」が使える位置にある。** r1 の J2 は
  基板の右端（x=180）から **3.0mm**、5 本が端と平行。裏面に部品なし。表面は D3（緑 LED）がピン 1 の 5mm 上、
  SW7（リセット）がピン 5 の 5.4mm 下、0402 の R20〜R23 が 2.5mm 内側。買うときは「端からピンまでの距離」が
  3mm 前後の製品を選ぶ。**r2 でもこの距離と周囲の空きを変えない**
- 当てる前に **`r2p2dev.py` の注意（書き込み直後に UART へ送らない）** はそのまま守る
