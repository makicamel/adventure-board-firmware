## J2 の並び（2×3 ソケット）

Debug Probe 付属ケーブルの並びに合わせる。プローブ側の表記は SWD が SC / GND / SD、UART が TX / GND / RX。

| 列 | ピン 1 | ピン 2 | ピン 3 | 刺すケーブル |
|---|---|---|---|---|
| SWD | SWCLK | GND | SWDIO | プローブの SWD ケーブル |
| UART | UART_TX（GPIO0、基板→プローブ） | GND | UART_RX（GPIO1、プローブ→基板） | プローブの UART ケーブル |

⚠ UART は基板の TX をプローブの RX に入れる。プローブのケーブルの「TX」はプローブから出る信号なので、
基板側は **UART_RX（GPIO1）** をケーブルの TX の位置に置く。上の表はその向きで書いてある
（列の並びが「基板の TX / GND / 基板の RX」= ケーブルの「RX / GND / TX」に当たる）。
r2 の回路図で、ケーブルを刺したときに交差になっているか必ず確認する。

GND が 2 本になるが問題ない。
