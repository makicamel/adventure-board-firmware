# DS100（ALIENTEK のハンディオシロ）の使い方

2ch、帯域 50MHz、250MSa/s、記録長 128K 点、電池駆動（約 7 時間）。プローブは MCX コネクタ。
元資料はユーザーマニュアル V1.7（ファーム V3.7 向け。`c:/Users/kishi/Downloads/DS100 Mini Digital Oscilloscope(3)/`）。
このファイルは、基板を測るときに要る操作だけを抜き出したもの。

## キーとホイール

| 操作 | 働き |
|---|---|
| **ホイール I** | 右のメニューバーの項目を選ぶ |
| **ホイール II** | 選んだ項目の値を変える |
| **キー A** | オートセット。まずこれで波形を出す |
| **キー M** | メニューを開く / 決定 |
| **キー E** | 戻る / 波形を中央に戻す。2 回押しでチャンネル切り替え |
| **キー P** | 長押しで電源、短押しで一時停止 / 再開 |
| **M + E 同時押し** | 画面を BMP で保存（USB モード中は不可） |
| E を押しながらホイール I / II | 時間軸 / 電圧軸 |
| M を押しながらホイール I / II | 横位置 / 縦位置 |

メニューバーは **2 ページ**ある。Probe、Sweep、計測（H-Meas / V-Meas）は 2 ページ目。
キーは壊れやすいので強く押さない。プローブの抜き差しはまっすぐに。

## 測る前の設定

1. **プローブ根元のスイッチ**（X1 / X10）を決め、Channel → CHA（または CHB）→ **Probe** を同じ値にする。
   合っていないと読みが 10 倍ずれる。既定は X1
2. **Couple** を DC か AC にする。**「--」はチャンネル OFF**。**CHB は既定で OFF** なので、
   使うときは CHB の Couple を DC / AC にして開く
3. **Sweep**（2 ページ目）を AUTO。信号が無くても画面が流れる
4. **T-type** を CHA-U（CHA の立ち上がり）。T-thr でしきい値

### X1 と X10 の使い分け

**電圧軸の最小 10mV/div は X1 のときの値。X10 にすると最小 100mV/div になる。**

| プローブ | 帯域 | 入力容量 | 向いているもの |
|---|---|---|---|
| X1 | 20MHz | 50pF | **小さい信号**（フィルタ後の音声、電源のリップル、mV〜数百 mV） |
| X10 | 140MHz | 15pF | 3.3V / 5V の矩形波、速いエッジ |

X1 の 50pF は、1kΩ 程度の節なら 3MHz まで影響しない。10kΩ 以上の節では波形がなまるので X10 にする。
入力は X1 で ±40V まで。

## 読む

- **自動計測**: Channel で対象を選び、2 ページ目の **V-Meas1 / V-Meas2** に Vp-p、Vrms、Vavg など、
  **H-Meas1 / H-Meas2** に Freq、+Duty などを置く。**画面に出ている範囲だけを計算する**ので、
  数周期が収まる時間軸にする
- **カーソル**: H-Meas に X2-1、V-Meas に Y2-1 を置くと X1 / X2 / Y1 / Y2 が出る
- 読みにくいときは P で止めてから読む

## 2 本の差（差動出力など）

1. CHA と CHB を同じプローブ倍率・同じ Couple・同じ V/div にする
2. Channel → **Math**、OP → **A−B**。Scale と Offset を調整
3. 他に A+B、A×B、A/B、Abs、**FFT**（Source を選び、Center と Hz/Div で範囲）

2 チャンネル同時で時間軸 200ns/div 以下のとき、15ns より速いエッジは補間で歪んで見える（FAQ 10.3）。
信号のせいではない。

## 保存と取り出し

| 形式 | 手順 | 中身 |
|---|---|---|
| **BMP** | M + E 同時押し | 画面そのまま（自動計測の数字も写る）。すぐ撮れる |
| **CSV** | **先に P で止める** → M → Save Wave → csv → ホイール II で名前 → M | 128K 点の生データ。約 25 秒かかる。Math は入らない |

CSV の中身（実物で確認）: 1 行目が `CHA(mV)  probe:X1,sampling rate : 200000000`、2 行目から 1 列で mV の整数、CRLF。
**4000 点 = 画面 1 枚ぶん**（横 10 div。2µs/div なら 20µs、200MS/s）。`numpy.loadtxt(path, skiprows=1)` で読める。
点数と単位は設定で変わる: 1V/div・2µs/div で止めて保存したら `CHA(V)`・小数・**100,000 点 = 500µs**（トリガは中央）だった。
画面の外まで入っているので、画面より長い時間の様子が分かる。ヘッダの sampling rate と行数で確かめること。

取り出しは USB モード: M → Other → USB → M。PC からストレージとして見える。E で戻る。
BMP は **4bit の RLE 圧縮**で、ヘッダのファイルサイズも実際と違うため、PIL などでは化ける。
`tools/ds100bmp.py S001.BMP` で PNG（2 倍）に変換できる。
ファイル名は番号だけなので、どの番号がどの測定かを控えておく。

## GND の取り方

- GND クリップは測る点の**近く**に、リードは短く。長い GND リードはスイッチング（D 級アンプの 250kHz など）を拾い、
  それ自体がノイズに見える
- 2 本使うときは両方のクリップを同じ GND に
- 電池駆動なので PC の GND とは絶縁されている。基板の GND に落として問題ない
- 付属のワニ口クリップは波形発生器の OUT 専用。CHA / CHB に挿さない（コネクタが緩む）

## 内蔵の波形発生器

M → Wave Gen。矩形波 1Hz〜10MHz、正弦波 / 三角波 / 鋸歯状波 1Hz〜50kHz、3Vpp。
プローブの補正（X10 のとき、1kHz 矩形波の角が丸い / 尖る → プローブのトリマを回す）にも使う。

## 音声の調査で使った設定

[../audio-quality/report.md](../audio-quality/report.md) の A-4。`t19_scope_hold.rb` で各状態を保つ。

| 測る場所 | プローブ | Couple | 目安 |
|---|---|---|---|
| J6（フィルタ出口、アンプ入口） | **X1** | AC | 10〜200mV/div、2µs/div（150kHz）、10µs/div（20kHz）、20ns/div（2MHz） |
| J3（生の PWM 3.3V） | X10 | DC | 1V/div、2µs/div |
| VO+ / VO−（スピーカー端子） | X10 ×2 → Math A−B | DC | 2V/div、2µs/div と 100µs/div |
| C23 / C27（IN− の基準、5V） | X1 | AC | 10〜50mV/div |

最初に何も出していない状態で床（無信号時の Vpp）を読んでおき、小さい信号はそれとの比較で判断する。
